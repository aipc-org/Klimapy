## 接口与计算口径

`aggregate(..., input_frequency="monthly")` 显式接受每月一个代表完整月份的样本。月均值按日历实际月长加权；月累计量直接求和；min/max 比较月值。所有操作以有效样本所代表的日数检查完整目标周期覆盖率，缺整月不会被当成完整季度或年份。支持月中时间戳、跨年 DJF 和非标准日历，拒绝同月重复样本。原有日输入默认行为保留。

`evaluate(..., dims=("lat", "lon"), cell_area=area)` 沿指定空间维度汇总格点误差，可输出逐时间步区域评分；同时选择时间与空间维度可输出整个样本集合的评分。无时间维度的空间 Field 也可以评估。面积必须为平方米单位、匹配维度坐标、有限且非负，零面积排除格点。归约后的结果保留其他维度。默认不传面积时仍为等权的逐格点时间评估。

各项加权矩、配对缺测掩膜和覆盖率采用同一权重。`valid_weight_fraction` 给出有效权重占比，`n_valid` 给出正权重有限配对数。面积整体缩放不改变结果。Rust 在每个输出单元内归一化面积尺度，使用在线加权矩计算方差、协方差和中心化误差。区域 RMSE 直接对格点平方误差加权，并非格点 RMSE 的平均，也非区域平均序列的 RMSE。

数值计算保持在 Rust；Python 只组织元数据、日历时长、数组布局和参数检查。C ABI 更新为 7，以拒绝过期的本地二进制。未增加 Python 依赖。

## 当前边界

- 月资料必须代表完整日历月；不根据缺失的 CF 时间边界推断实际观测时长。
- 时间与空间同时归约时，各时间样本等权，不自动对月样本使用时长权重。
- 面积由调用者提供，不自动用 cos(lat) 冒充真实面积。
- Field 仍使用一维维度坐标，不新增曲线网格辅助坐标；评估仍为内存数组接口，未新增集合流式评估。
- 尚未加入通量单位积分、CF time_bnds、通用 QC JSON 和集合模式评估。
- 本地 Linux x86_64 wheel 已验收；未发布版本、提交或推送，也未宣称其他平台已构建通过。
