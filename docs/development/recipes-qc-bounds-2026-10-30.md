# CF 时间边界、QC 与任务配置验收：2026-10-30

使用说明见[CF 时间边界、QC 与 JSON 配置](../tools/recipes.md)，可修改并运行[月平均评估模板](../../examples/recipes/monthly-evaluation.json)。

## 已实现

- Field 新增可选 time_bounds，校验形状、有限性、顺序、不重叠和时间戳包含关系；切片、NetCDF 读写及变量推断支持时间边界。
- 多文件集合统一不同 CF 起点/单位下的边界和时间戳，保留日内偏移；边界缺失口径须一致，拒绝跨文件重叠。
- 月/季/年聚合写出完整目标周期边界；有输入边界时检查完整日/月。模式评估检查时间点与边界一致，空间评分保留未归约的时间边界。
- Rust 生成有限值、NaN、无穷值、负值、范围阈值计数及极值；Python 组织 JSON 元数据、日历、日期与边界缺口，不自动改值或猜测单位。
- JSON runner 支持顺序 load/aggregate/evaluate，显式引用前置步骤，可引用面积步骤。每步输出 QC，Field 输出 NetCDF；run.json 保留配置、父步骤、输入和输出哈希、版本、平台、代码指纹和成功/失败记录。
- 输出目录必须为新目录，避免覆盖旧结果；失败后保留已完成步骤及错误记录。
- 原生 ABI 更新为 8，未增加 Python 运行依赖。

## 限定范围

时间边界只覆盖 time 维度，未实现任意 CF 辅助坐标或 CF 全面认证。聚合只支持完整日历日/月输入，不是任意区间通量积分。QC 针对解码数值：现有 NetCDF 读取器会将原始非有限值和 CF 掩膜值变为 NaN，不能由文件 QC 反推原始编码中的无穷值数量。

runner 是有限操作的顺序工作流，不包含缓存、断点恢复、并行调度或 ETCCDI/BCSD recipe。评价集合时会物化数组；QC 本身分块，输入完整 SHA-256 仍需额外全文件 I/O。QC 记录异常，不自动充当阈值门禁。重复运行保证可比的科学结果，不承诺时间戳、随机运行 ID 或 NetCDF 字节哈希相同。

验收针对本机 Linux x86_64 wheel；未据此宣称其他平台通过。改动未提交或推送。
