## 本次发现与修复

1. 集合与事件接口已有源代码，但旧的已加载原生库没有相应符号。重新构建并验证源码/安装包直接调用；仅运行原有测试会漏掉这一问题。
2. 复合事件此前检查时间坐标却没有检查时间边界。现在边界不一致时拒绝输入，增加回归测试。
3. 新增集合及事件四项小例子验收：成员先在模式内平均、模式权重与缺测覆盖、有限间隔合并/缺测中断、复合事件的不同单位与时间边界。
4. 增加五项独立真实切片对照：集合均值、中位数、5%/95% 分位数及事件起止/强度。独立参考采用 NumPy 分位数和布尔变化点，不引用生产实现。

## 科学与分发限制

- CN05.1 逐日对照使用 2019–2020 年的 6×8 空间切片；SPI 使用 1961–2018 年月资料切片。不是全区域、全部原始数据验收。
- 月降水原资料单位需依据提供者说明解释为 mm/day，再显式乘月长。原时间边界末端不是下个月起点；回归夹具显式采用标记的完整月产品并去掉不完整边界，未修改原文件。生产接口不自动猜测单位或修复边界。
- SPI 对照包含尺度 3 和 12；SPEI 当前独立数值验证使用合成 PET，尚不能称为长期真实 PET 验证。新下载资料的负值、空单位和年限问题见 `public-validation-data-2026-10-30.md`。
- 显著性 Rust 内核虽已有代码，公开 Python 接口及完整独立统计验收仍缺失，未列为已通过。
- QDM、二维曲线网格、周期与掩膜的完整扩展、湿度/风速/辐射配对订正、缓存恢复及剩余研究诊断尚未全部完成。不能通过网站展示或源文件存在认定实现完成。
- wheel 仅在本机 Linux 验证，未覆盖 macOS、Windows 或所有 Linux 发行版。版本仍为 1.2.1 的本地开发构建，没有据此发布新版本。
