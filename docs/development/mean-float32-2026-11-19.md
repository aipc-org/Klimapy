# Direct float32 climate accumulation

The additive `climate_accumulate_f32` C entry point reads float32 directly and
accumulates into float64 sums and int32 counts. It preserves time order, grouping,
-1 skipped groups, non-finite filtering and checked count overflow. No new
numerical backend or historical Python dependency is introduced.

The Python wrapper chooses this entry point for native-endian float32 inputs,
ensuring contiguous aligned storage. Other dtypes retain the existing float64
Rust entry point. Older native libraries without the additive symbol retain the
existing Rust conversion path; the existing ABI value/signatures do not change.

On the same 256×360×640 float32 benchmark, five warmed runs in conda Test:
median 159.31 ms before, 46.72 ms after (3.41x). float64 after: 56.45 ms,
comparable to the earlier 54.69 ms. Optimized outputs are bitwise equal to the
previous accumulators for the benchmark (including matching NaNs).
These measurements exclude file I/O and input generation/loading. They do not
predict end-to-end speedups on NetCDF files, especially float64 source files.

Source acceptance: 113 native tests passed in clean conda Test, then 128
independent Test/Test1 CN05.1 tile checks passed. Built wheel acceptance:
113 native tests and 128 tile checks separately passed with --installed and
source-path injection disabled. The new float32 real-data mean check has zero
maximum absolute error; scope is the existing documented 6×8 tile for 2019–2020,
not the entire real dataset. Tests also cover Fortran/strided/non-native-endian
arrays, unaligned float32 storage, missing/non-finite values, grouping, multiple
blocks, unchanged integer/double handling and invalid indices/count overflow.

Commands: `python tools/manage.py test`, `python tools/manage.py compare`,
then both commands with `--installed` after installing the built wheel into Test.
No historical dependencies were added to Test. Linux wheel was built locally;
Windows/macOS binaries were not rebuilt in this task.

Raw benchmark/acceptance summary: `benchmarks/results/mean-float32-2026-11-19.json`.
