01 / DESIGN PHILOSOPHY

接口清晰，
计算有据可循。

围绕气候分析工作流组织功能。让数值算法、数据语义和研究结果各有明确的位置。

01

Python 组织研究流程

负责参数校验、时间与坐标元数据、结果组织。使用 Field 承载数值、维度、坐标和属性，批量指标以字典返回。

02

Rust 承担底层计算

数值内核由必需的 Rust 引擎执行，不维护可切换的 Python 数值后备实现。Python 运行依赖保持为 NumPy。

03

独立参考，明确边界

最小环境运行生产代码，独立参考环境调用其他库进行对照。记录缺测、基准期和日历口径，不把切片测试当作全量验收。

02 / GET STARTED

一次安装，
开始你的分析。

在独立环境中安装 Klimapy。以下示例展示当前主分支的原生接口。

版本提示

网站说明对应当前主分支。PyPI 发布包可能尚未包含全部迁移接口，请核对发布记录；需要这些接口时从源码安装。

源码构建需要 Cargo。NetCDF 文件读写需要系统 libnetcdf / HDF5；Shapefile 和 CRS 转换另需原生 GDAL。

python -m pip install klimapy

# 查看已安装版本
python -m pip show klimapy
