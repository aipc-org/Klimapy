线性代数

svd

klimapy.native.svd(data, *, n_modes=None, tol=1e-12, max_sweeps=100)

Return U, s, Vt with data ~= (U * s) @ Vt, compact shapes only.

Rust uses scaled one-sided Jacobi rotations without forming a covariance matrix. n_modes truncates a complete dense factorization; it is not a randomized or out-of-core solver. Mode signs are fixed deterministically, while repeated singular subspaces remain non-unique.

源码

EOFResult

klimapy.native.EOFResult

EOFResult.reconstruct(self, n_modes=None, *, add_mean=True)

Physical-unit patterns and unscaled PCs; weighted patterns are orthonormal.

eigenvalues = s**2/(ntime-ddof). Fractions always use total variance across all modes, even when only n_modes are returned. Excluded cells remain NaN.

源码

eof

klimapy.native.eof(data, *, n_modes=None, weights=None, lat=None, center=True, ddof=1, tol=1e-12, max_sweeps=100)

EOF analysis of (time, *space) real arrays with explicit area weights.

weights are nonnegative AREA weights (broadcast to spatial dimensions), not their square roots. Rust uses sqrt(weights) for the SVD and unweights output patterns. For (time, lat, lon), lat computes cos(latitude) area weights. All-NaN cells and zero weights are excluded; intermittent NaNs are rejected. center=False performs uncentered decomposition; eigenvalues then describe second moments rather than centered covariance. No detrending is implicit.

Regridder

klimapy.Interpolation.Regridder

Regridder.close(self)

Reusable Rust weights; supports explicit close/context management.

No implicit extrapolation or filling. Conservative destinations require complete coverage; second order uses piecewise linear gradient moments. Patch is a local quadratic 3x3 least-squares fit, not ESMF multi-patch.

动态生成的 ETCCDI 指标

这些函数通过工厂创建，不会出现在静态 def 列表中。完整口径与返回频率见 ETCCDI。

类别 函数与签名
固定阈值降水 R10mm / R20mm / R25mm / R50mm 的 _precipitation、_days、_intensity、_ratio：metric(pr, *, min_valid_fraction=0.9)
百分位降水 R90mm / R95mm / R99mm 的相同四种后缀：metric(pr, baseline_pr=None, baseline_years=None, *, min_valid_fraction=0.9)
温度阈值与极值 FD(tn)、SU(tx)、ID(tx)、TR(tn)、TXx(tx)、TNx(tn)、TXn(tx)、TNn(tn)，带 min_valid_fraction=0.9

这里的 metric 代表所选函数名称，不是额外导出的函数。百分位降水必须显式提供基准期；温度百分位函数的 bootstrap 默认行为见其独立签名及指南。
