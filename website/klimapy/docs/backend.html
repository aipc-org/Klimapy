Rust 引擎与原生数据层

生产包只使用 NumPy/标准库封装接口、坐标、日历和结果。数值计算由必需 Rust 引擎执行， 没有可切换的 Python 后备算法。旧 Python 框架仅存在于独立 Test1 参考进程。

计算职责

模块 Rust 职责
BC 清洗拟合样本、线性分位数、纯 Rust FITPACK 三次平滑样条及夹持求值
SD 气候态累计与均值、低频谐波平滑、空间计划、降水比值与块级重建
ETCCDI 聚合/计数、滚动最大、连续事件、type-8 百分位、温度比例/持续事件及 GSL
插值 双线性、球面最近邻、局部二次拟合、一阶/二阶球面矩形守恒权重与求值
变率 季节异常、去趋势、年度标准差和覆盖率、年度相对趋势
SVD/EOF 分解、权重处理、EOF 与重建
空间工具 空间均值、Polygon/MultiPolygon 与孔洞掩膜、Float32 GeoTIFF 写出
文件 Rust 调用系统 libnetcdf 分块读写、压缩、缺测/打包解码

Python 准备分组标签、参考期索引、bootstrap 年份组合并组织结果；重复样本百分位、 各副本指标及最终均值仍调用 Rust。GeoJSON 使用标准库读取；Shapefile 及 CRS 转换 使用可选的原生 GDAL C API，随后将 WGS84 几何交给 Rust 掩膜，不导入 Python GIS 库。

构建与 ABI

conda run -n Test python -m pip install --no-deps --no-build-isolation .
conda run -n Test python setup.py build_ext --inplace
conda run -n Test python tools/manage.py test

ABI 为 4，旧动态库必须重建。Cargo 缺失或编译失败会报错；KLIMAPY_BUILD_RUST=0 和 KLIMAPY_BACKEND=python 均不支持。旧 auto 值等价于 rust，不回退。 klimapy.backend_info() 可检查原生库状态。

FITPACK 来源为 splinefit 0.4.1 的独立纯 Rust 引擎，源码、校验值、控制流补丁说明及 MIT/Apache 许可 保留在 rust/vendor/splinefit，相应许可也随 wheel 安装。构建不联网下载依赖， 无需 Fortran。BC 的初始 knot workspace 和扩容后重拟合对应 Test1 的 SciPy 1.18.1 UnivariateSpline 行为， 不以另一种平滑算法替代旧三次样条。

原生对象与内存

klimapy.native.Field 包含 values/dims/coords/attrs/coordinate_attrs；高层入口统一 使用它，批量指标返回字段字典。Dataset/Variable 提供显式可关闭的文件句柄， read_field(indexers=...) 只读取指定区域，关闭文件后返回 eager Field。 Field 不是旧框架克隆，不提供任意 groupby、resample 或 GIS accessor。

BC/SD 的文件入口使用 PrecipSource，保持有界读取，模型行和观测时间块按需载入； BC 输出可为 memmap，SD 中间气候态使用临时磁盘缓冲。独立调用者负责关闭 BC 结果。 空间计划/传递函数都支持 close/上下文管理；关闭后求值明确报错。

文件运行库及边界

系统需提供 libnetcdf（读 NetCDF4 时还需其 HDF5 依赖）；自动发现失败时设置 KLIMAPY_NETCDF_LIBRARY。Shapefile 可选设置 KLIMAPY_GDAL_LIBRARY。 这些是原生共享库路径，不是 Python 包。运行库目前不随 wheel 打包。 Rust 对自己的 NetCDF 调用串行加锁，不承诺和其他进程内绑定并发安全。

NetCDF 支持数值变量、单位步长切片/取点、显式分组路径读取、数值/字符串属性、 缺测与打包解码、根组固定维度变量创建、压缩。默认读取 float64；超过 2^53 的 int64/uint64 不适合无损 ID 读取。尚不支持 _Unsigned=true、字符串/复合变量、 无限维追加、创建分组、跨步/花式文件索引。write_raw 写存储值，不隐式反向打包。 不自写 HDF5 解析器，也不将 Dataset 宣称为完整 CF 数据框架。

日历元数据支持 Gregorian/standard（1582 年改革断档）、proleptic Gregorian、Julian、 noleap/all_leap/360_day，年份范围 1..9999；每日时间必须有序且无重复。 数值时间使用 CF since 单位或 YYYYMMDD。高层需要时将缺日补为 NaN，绝不按文件名 猜测年份。CN05.1 的 2019 Pre 时间修正是用户确认的特例，记录留在本地 data 内。

GeoTIFF 为 WGS84 规则矩形网格、Float32、PixelIsArea、单 strip、无压缩， classic TIFF 单文件须小于 4 GB；不规则网格明确拒绝。矢量掩膜支持 Polygon/ MultiPolygon、孔洞和边界相交语义，不处理跨日期变更线的包裹几何。
