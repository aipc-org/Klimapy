常见问题

结果为什么出现 NaN

核对有效日比例、变量单位、基准期样本和目标网格覆盖范围。全缺失数据不会填零；普通插值区域外不外推。每个功能章节说明自己的有效性条件。

百分位指标为什么与其他软件不同

先统一湿日阈值、分位数方法、基准期、日序窗口、闰日规则和 bootstrap 参数，再比较结果。相同的函数名称不保证默认参数完全相同。

如何控制内存

读取文件时用 indexers 限制区域；BCSD 可配置时间块、空间块和工作目录。重复插值复用 Regridder。EOF/SVD 仍是稠密矩阵分解，减少返回模态数不会将其变成稀疏求解器。

为什么默认气候态要求 1991–2020

默认基准期采用最近一个以 0 结尾的完整年份向前 30 年，2026 年对应 1991–2020。数据未覆盖这一时段时，应显式指定自己研究的参考期，程序不会静默缩短它。

为什么输出路径已存在会报错

NetCDF 和 CSV 的保存接口拒绝覆盖已有结果。为新的实验选择新路径；其他文件流程的行为见各格式章节。

如何反馈问题

在 GitHub Issue 中附上软件版本、操作系统、输入维度、单位、日历、最小可复现代码和完整错误。可用小型合成 Field 复现，避免上传受限资料或访问凭据。
